# Nexora

Responsive movie and TV discovery demo. Includes a landing page, testimonials, movie catalogue, account flows, watchlists, newsletter signup, and a small local API.

## Run locally

Install Node.js 20 or later, then run `npm start` and open `http://localhost:4173`.

No package install or external database is required. The local server writes demo data to `data/nexora.json`.

The demo is not a streaming service: movie data is sample content and the trailer action opens a title preview.
